# 맵·속성·버프 원본 fixture

아이템 fixture와 combat fixture에 덧붙이는 직접 작성한 CSV IES·XML/TSV 입력이다.
게임 다운로드나 현재 지역 JSON에 의존하지 않는다. `expected_world.json`은 원본 값으로 계산한 기대값이며
파서 출력을 자동 복제한 golden이 아니다.

| 입력 | 선택한 경로 |
| --- | --- |
| map.ies 3행 | 번역·유형·CM/워프·수치·지도 연결과 1/2층 연결 |
| zonedrop 3파일 | 일반 직접 드롭, 대문자 `f_` 변형, unknownsanctuary의 비율 단위 |
| dropgroup 2파일 | 가중치로 나눈 그룹 확률; 대소문자가 다른 그룹 파일 찾기 |
| anchor/gentype | 두 몬스터 생성점의 좌표·인구수 병합, NPC 생성, ArgStr2의 아이템 생성 |
| monster_npc.ies | 실제 NPC 파싱과 맵의 NPC 연결 |
| ability.ies와 직업별 Ability 파일 | 기본·보충 스킬 ClassName 연결, 직업 연결, 비활성 정리, 은퇴/비직업 스킬 처리 |
| buff_hardskill/buff/buff_monster/buff_contents | 네 파일 모두 실제 행을 파싱; Common_ 제외, optional 그룹, YES/NO, 원본 ms·스택 |
| language XML·world.tsv | 지도·속성·버프 이름과 설명의 실제 번역 경로 |

일반 맵의 직접 확률은 `1250 / 100 = 12.5%`다.
그룹은 `2000 / 100 = 20%`에 가중치 3:1을 곱해 dust 15%, sword 5%다.
특수 맵은 `125000 / 10000 = 12.5%`이며 그룹도 `500000 / 10000 = 50%`에
가중치 1:3을 적용해 dust 12.5%, sword 37.5%다.
맵 드롭 수량 0은 원본에 신뢰할 수 있는 수량이 없음을 나타내는 기존 호환값이다.

지도 크기 200×100의 중심은 (100,50)이고 MAP_SCALE은 0.5다.
몬스터 원본 (20,10), (-20,-10)은 (60,20), (40,30)으로 변환된다.
생성 수 2+1은 3이며 재생성 2500ms는 2.5초다.
이 경로는 bbox=(0,0,0,0)을 사용하며 PNG 지도 생성·자르기를 실행하지 않는다.

속성의 Link_Skills는 스킬 **ClassName**, 스킬·직업의 Link_Attributes는 속성 ID다.
비활성 속성을 제거하며 은퇴한 비직업 스킬 참조는 공개 JSON에서 보존하고 importer가 건너뛴다.
버프 ApplyTime은 JSON의 원본 정수 문자열을 DB 정수 ms로 저장한다.
3500ms의 현재 화면 표시는 정수 초인 `3 s`다.

원본 값 변경, 대소문자 파일 조회, 반복 빌드와 맵 관계 재구성,
누락 입력·잘못된 숫자·지도 연결·중복 관계가 공개 파일을 보존하는지 검사한다.
가중치 합계가 0인 그룹과 아무 참조가 없는 zonedrop 행은 기존 규칙대로 드롭을 만들지 않는다.
드롭 그룹 파일이 없는 경우의 기존 선택적 처리도 유지한다.
원본에서 같은 맵/아이템 부모 쌍이 여러 번 나오면 공통 계약이 거부하며 임의로 확률을 합치지 않는다.

`harness/world_tests.py`는 이 원본을 실제 migrations·ORM으로 적재하고
맵·속성·버프 검색/상세와 아이템의 맵 역참조를 검사한다.
수치 갱신·속성 연결 변경·맵 드롭/생성 관계·버프 삭제, 실패 후 롤백·재시도를 포함한다.

샘플은 작은 합성 iTOS 입력이다. 다른 지역·실제 게임 계산식·모든 맵/속성/버프 유형,
지도 이미지 생성·브라우저 canvas 표시·전체 main.py·운영 MySQL은 포함하지 않는다.
속성 UpgradePrice/Unlock의 Lua 계산은 현재 선택한 파서 경로에서 실행하지 않는다.
